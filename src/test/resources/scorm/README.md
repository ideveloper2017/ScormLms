# SCORM end-to-end fixtures

Bu katalogdagi SCORM 1.2 va SCORM 2004 namunalar loyiha uchun yozilgan mustaqil test kontentidir.
Test ularni ish vaqtida ZIP/PIF paketga yig'ib, import, launch, runtime commit, finish va qayta ochish oqimini tekshiradi.

Har bir namuna:

- standart `imsmanifest.xml` fayliga;
- brauzerda ishga tushadigan SCO `index.html` fayliga;
- tegishli SCORM runtime API chaqiruvlariga ega.
